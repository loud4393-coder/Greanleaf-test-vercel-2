# Greenleaf

Лёгкая тестовая версия Telegram Mini App магазина Greenleaf.

## Что уже есть

- каталог товаров;
- корзина;
- оформление заказа;
- доставка или самовывоз;
- сохранение заказа;
- Telegram-уведомление админу через Bot API;
- API для каталога;
- API для заказов.

## Переменные окружения

В Vercel добавь:

- `BOT_TOKEN` — токен бота от BotFather;
- `ADMIN_ID` — Telegram ID администратора.

Секреты не нужно записывать в GitHub.

## Проверка

1. Открой `/health`.
2. Открой главную страницу.
3. Добавь товар в корзину.
4. Оформи тестовый заказ.
5. После добавления переменных окружения проверь уведомление в Telegram.

## Важное ограничение теста

SQLite на Vercel не является подходящей постоянной production-базой: файловая система serverless-окружения не предназначена для надёжного постоянного хранения. На этом этапе SQLite используется для проверки логики. Перед боевым запуском подключим постоянную БД.
